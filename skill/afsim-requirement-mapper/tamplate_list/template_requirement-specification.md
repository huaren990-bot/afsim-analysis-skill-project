# 需求规范文档规范
1. **面向对象**：本文档同时面向没有软件开发基础的提需求人员和没有算法基础的C++程序开发人员：
   1. 需要将需求人员提供的模糊需求文档转换成能够用c++程序实现的功能需求文档。
   2. 保证需求人员的需求能够实现。
   3. 所有需求人员的需求都必须在需求规范文档中。
   4. 保证开发人员能够明确需要通过代码实现什么功能。
2. **中文注释全覆盖**：算法卡片应当是可供只会中文的人员阅读和理解的产物，本文所有章节都必须添加中文注释。
3. **语言统一**：文档中不同章节在表示相同内容时使用的标识符和名称应当统一，语言风格应当保持严谨准确。
4. **格式标准化**：需求规范文档的格式，尤其是章节结构、表格表头、非必要不允许擅自修改，如需要修改，请询问人工。
5. **自有系统**：如果没有任何有关自有系统的文件，默认自有系统为什么功能都没有的空系统。
