## 实现流程

1. 流程图如下：

```mermaid
sequenceDiagram
    participant Main as 主程序
    participant A as 函数A<br>filter
    participant B as 函数B<br>transform
    participant C as 函数C<br>validate
    participant D as 函数D<br>format
    participant E as 函数E<br>save

    Note over Main: 原始数据 data = 100

    Main->>+A: ① 调用 filter(data) <br> 传递值副本 (100)
    Note over A: 过滤处理，产生新值 90
    A-->>-Main: 返回 filter_result = 90

    Main->>+B: ② 调用 transform(filter_result) <br> 传递值副本 (90)
    Note over B: 变换处理，产生新值 180
    B-->>-Main: 返回 transform_result = 180

    Main->>+C: ③ 调用 validate(transform_result) <br> 传递值副本 (180)
    Note over C: 校验通过，原值不变 180
    C-->>-Main: 返回 validate_result = 180

    Main->>+D: ④ 调用 format(validate_result) <br> 传递值副本 (180)
    Note over D: 格式化处理，产生新值 "180.00"
    D-->>-Main: 返回 format_result = "180.00"

    Main->>+E: ⑤ 调用 save(format_result) <br> 传递值副本 ("180.00")
    Note over E: 保存处理，返回状态
    E-->>-Main: 返回 save_status = "ok"

    Note over Main: ⑥ 原始数据 data 仍为 100，<br>所有函数修改均不影响原始值
```
