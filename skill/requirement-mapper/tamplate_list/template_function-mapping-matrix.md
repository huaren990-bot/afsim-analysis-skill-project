# 功能映射矩阵 — function-mapping-matrix.md

1. **使用说明**：本模板用于生成 `docs/requirements/3_<requirement_index>-function-mapping-matrix.md`，生成文档展示每条需求对应的 AFSIM 功能和目标系统当前的能力状态，是需求覆盖度分析的汇总视图。  

2. **填写要求**：
- “AFSIM 对应功能”需包含具体的函数/类名，以及简要功能说明。若 AFSIM 中也无对应功能（状态为 🆕），此列填”无”。
- “目标系统当前功能”需引用目标系统索引中的函数名或模块名，若无则为”无”。
- “匹配证据/差异说明”中，对于部分满足的情形，应说明缺失的参数、接口差异或耦合限制。
- 对于 🆕 缺失（AFSIM无参考）的项，应在匹配证据中说明 AFSIM 索引搜索范围及未找到匹配的原因，并注明迁移方式为 novel（全新设计）。
- 替换 `{...}` 占位内容，状态栏使用 ✅（完全满足）、⚠️（部分满足）、❌（缺失）、🆕（缺失-AFSIM无参考）、❓（无法判断）。
- 对于无法判断（❓）的项，应在备注中列明需要人工澄清的具体问题。
