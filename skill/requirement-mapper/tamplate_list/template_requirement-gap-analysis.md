# 需求缺口分析报告 — requirement-gap-analysis.md

1. **使用说明**：本模板用于生成 `docs/requirements/requirement-gap-analysis.md`， 生成文档总结需求覆盖度情况，列出所有能力缺口，并按优先级排序，给出总体迁移建议。  

2. **填写要求**：
   1. 以下章节需根据实际分析结果填充，替换 `{...}` 占位内容。
   2. 以下出现了`{无/如下表所示}`的部分，表示如果没有内容，就1）填写`无`，2）把表格删掉；如果有内容，1）填写`如下表所示`，2）填写表格。
