# context-handoff.md 模板

## 用途

阶段间上下文传递的标准格式。每个阶段完成后，分析 Agent 必须填写此文件，作为下游阶段的输入契约。
文件命名：`docs/project-boundary/context-handoff-phase<N>.md`

```markdown

> **分析 Agent**：<skill name>
> **验证 Agent**：<skill name>

---
```

## 填写规则

1. 每个阶段完成后**必须**填写此文件，不可跳过。
2. "下游阶段输入契约"中列出的文件必须是真实存在且可读取的。
3. "已知问题与限制"必须诚实记录，不可隐瞒。
4. 验证报告摘要必须与实际验证报告一致。
5. 关键统计数据必须与产出文件实际行数/条目数一致。
6. 覆盖闭环统计必须诚实填写；没有对应阶段的覆盖项填 `不适用`，不可留空。
7. 未解释缺失项超过 50 条时，在本节列出前 50 条，并指向完整清单文件。
