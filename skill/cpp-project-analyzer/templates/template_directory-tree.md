# directory-tree.md

## 要求

对 `source_root` 下的每个 `extract_root` 生成深度 ≤ 3 的目录结构树。

## 内容

1. **根路径**：记录 `source_root` 绝对路径和扫描深度。
2. **afsim-2_9** 中列出所有顶级条目（文件和目录）及其文件计数。
3. **src/** 中列出所有顶级条目（文件和目录）及其文件计数。
4. **目录结构**：以树形文本展示深度 ≤ 3 的完整目录结构。
5. **统计摘要**：各 extract_root 的目录数和总文件数。

## 格式

```markdown
# Source Root 目录树

> 根路径: `source_root`
> 扫描深度: 4 层

## <extract_root>/
### 顶级文件/目录
- `file_or_dir/` (N files)

### 目录结构 (depth ≤ 3)
\`\`\`
extract_root/
├── dir1/
│   ├── sub1/
│   └── sub2/
└── dir2/
\`\`\`

## 统计摘要
| 提取根 | 目录数 (≤depth 3) | 总文件数 |
|--------|-------------------|---------|
| `xxx`  | N                 | N       |
```

## 说明

- 树形结构使用 `├──`、`└──`、`│` 字符绘制。
- 隐藏目录（`.git`、`.codegraph` 等）默认不展示。
- 仅展示目录名，不列出文件。
- 深度限制为 4 层，避免输出过长。
- 空目录保留，与 `find -type d` 行为一致。
